## Real sample provenance

The two `paper_attempt_*` files are copied from successful frozen final
generation attempt 0296. Their hashes are:

- payload JSON: `ceefc5b75d0e2b1a4776022ede6b7502e9cd6170d50e68450257f0c0e26f205f`
- token tensor: `2f3676358192eeba817d15e419d903aae530426f9812c6c962f72c7fb9d9d723`

`raw_subcircuit.json` is a portable JSON transcription of that attempt's
decoded graph. `cells.v` is a new smoke-only model and is not a PDK extract.

## Thin supplement code

- `sample_io.py`: JSON-to-PyG conversion and stable graph reporting.
- `validation.py`: named condition report using production object invariants
  and the frozen topology audit definition.
- `materialize.py`: direct assignment-preserving structural exporter and Yosys
  runner; it performs zero repair operations.
- `metrics.py`: deterministic sample counts, histograms, and fingerprint.
- `scripts/run_pipeline.py`: orchestration and expected-output comparison.

## Expected outputs

All files in `expected_outputs/` were generated by executing
`scripts/run_minimal_reproduction.sh --update-expected` with the tested
environment, not manually transcribed. `yosys.log` is the actual sanitized
reference log; the structured stable result is compared during normal runs.

## Compact paper records

Files under `paper_results/` are copied frozen CSV outputs. They are included
because they are small and directly map to paper tables. Full per-attempt and
per-reference inputs are omitted. `recomputed_compact_audit.json` is generated
from these CSVs by the included audit script.

## Deliberate omissions

The package excludes `.git`, caches, notebooks, logs with host metadata,
complete checkpoints, full datasets, full attempt directories, PDK files, and
unrelated historical experiments. See `LIMITATIONS.md` for scientific scope.
The unmodified upstream BSD notice is isolated in
`third_party/UPSTREAM_LICENSE`; the root license uses anonymous ELDA authorship.
